# DealFlow360 — Design System & Visual Guidelines

## Visual Character

The UI must feel:
- Precise
- Trustworthy
- Operational
- Financially credible
- Intelligent
- Calm
- Enterprise-grade

## Design Tokens

- Background: Sleek dark / slate palette with clean borders
- Typography: Inter / Outfit modern sans-serif
- Risk Representation: Severity labels, scores, icons, and rule explanations paired together (never color alone)

Refer to `docs/references/ui/` for explicit layout specifications.
